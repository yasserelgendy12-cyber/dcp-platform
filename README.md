# Data Collection Platform

Weekly project data collection tool (progress per P6 activity, HSE, document control, manpower & equipment, drawings, invoices) with P6 update export.

**Open the tool:** https://yasserelgendy12-cyber.github.io/dcp-platform/

- Single self-contained HTML file (`index.html`), bilingual English / Arabic.
- No project data is stored in this repository. Each project's database is a file in the project owner's OneDrive, linked in the tool with a OneDrive sharing link (Microsoft sign-in) or a synced folder.
